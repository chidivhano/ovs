# Oviaas Lifestyle Store (OVS)

Official e-commerce website for Oviaas Lifestyle Store.

## Overview
Oviaas Lifestyle is an exclusive lifestyle brand made in South Africa. Established in 2014, the brand started in the streets of Soweto, Johannesburg, combining streetwear, lifestyle, art, music, and entertainment.

## Pages
- `index.html` - Home Page
- `product.html` - Products & Summer Collection
- `about.html` - About Oviaas Lifestyle, Studios, & Records
- `contact.html` - Contact Information
- `members only.html` - Exclusive Members Only Drops

## Deployment
Automated deployment to GitHub Pages via GitHub Actions.
